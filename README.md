# Recipe-manager
This is a repository that contains code for recipe manager application 

## Goal

The goal of this project is to:
- Focus primarily on learning and developing the Go backend
- Keep the frontend simple

Technologies and tools used
- Golang standard library for backend (using HTTP server)
- React frontend built with Vite


## How to run the project 

Prerequisites:
- Go installed
- Node.js + npm installed

1. Build the frontend
   - cd frontend
   - npm install
   - npm run build

This generates the production-ready frontend in frontend/dist.

2. Run the backend
   - from the root directory
   - go run cmd/server/main.go


3. Open the application on http://localhost:8080
